# 🚀 Mini SaaS Backend

## 📌 Mục tiêu
Xây backend SaaS mini để học:

- ASP.NET Core Web API (MVC bỏ View)
- EF Core + SQL Server
- Service layer
- JWT Authentication
- File upload
- Background job
- Notification
- Realtime (SignalR)
